## 📌 Project Overview

Osteoporosis is a common bone disease that causes bones to become weak and more likely to fracture.

This project develops an end-to-end **Osteoporosis Risk Prediction System** using Machine Learning.

The system analyzes patient demographic, lifestyle, and medical information and uses a trained **Gradient Boosting Classifier** to predict the osteoporosis risk class.

The application provides an interactive web interface built with **Streamlit**, allowing users to enter patient information and receive a prediction and estimated risk probability.

---

## 🎯 Project Objectives

- Build a machine-learning model for osteoporosis risk prediction.
- Preprocess demographic, lifestyle, and medical data.
- Train and evaluate a Gradient Boosting model.
